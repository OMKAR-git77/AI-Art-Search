# AI-Powered Art Search Application

# Overview
This repository serves as the main documentation for the AI-Powered Art Search Application, a class project developed as part of the MS in Information technology program. The project is a full-stack application that enables users to search for artworks and designs based on visual similarities,styles,textures,color palettes, and emotional expressions using AI-driven multimodal search capabilities.
The application consists of two main components:

• Backend: Handles API endpoints, authentication, image processing, and vector-based similarity search.  
• Frontend: Provides a user-friendly interface for image uploads, searches, and result visualization.


This project was collaboratively developed with classmates, focusing on integrating AI technologies for art discovery. Key contributors include team members involved in design, implementation, and testing.

# Features
• AI_Powered Similarity Search: Upload images to find visually similar artworks using vector embeddings.  
• Bulk Image Upload and Processing: Support for uploading multiple images with automatic embedding generation.  
• Filters: Filter search results by style, texture, color palette, and emotional tone.  
• User Authentication: Secure login/logout with JWT tokens for protected routes.  
• API Documentation: Auto-generated Swagger docs for backend endpoints.  

# Technologies Used
Backend -  
• Framework: FastAPI 
• Databases: Weaviate(vector storage), SQLite(metadata)  
• Image Processings: Pillow(PIL)  
• Authentication: JWT  
• Embeddings: Placeholder for models like CLIP.  
• Other: Python, SQLAlchemy, pytest, Docker  

Frontend -  
• Framework: Next.js  
• Styling: Tailwind CSS  
• Language: TypeScript  
• Other: Node.js, Docker
